PROJECT QUESTIONS

Before we begin.

Do you build for Android and iOS?

We offer cross-platform Flutter development for Android and iOS, with platform-specific requirements, testing and store-release scope agreed separately.

Can you integrate an existing backend?

What happens after launch?

Maintenance, store updates, bug fixes and ownership of accounts and source code are defined in the project agreement.
